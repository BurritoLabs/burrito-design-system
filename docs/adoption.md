# Adoption order

1. Burrito Monitor — first production pilot.
2. Burrito WebApp — use a clean worktree from current `origin/main`.
3. Burrito AI.
4. Burrito Finder.
5. Burrito DApp Studio — keep editor chrome separate from generated-site themes.
6. Burrito Wallet Mobile — native loading, error, wallet, and approval surfaces; the WebView inherits WebApp styling.
7. Burrito DEX — formalize the current prototype as a Git repository.
8. Burrito Money and Burrito Labs websites — deferred by product decision.

The legacy `BurritoLabs/app` Station fork is reference-only and is not an adoption target.
