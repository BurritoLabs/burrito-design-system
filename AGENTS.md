# Burrito brand governance

For brand assets, wordmarks, or product adoption, read `docs/brand.md`. Its format applies by default to all existing and future Burrito company products, as explicitly requested by the user on 2026-09-08.

Preserve the approved **-1px tracking on both words**, shared Montserrat font, 24px icon / 20px type, 6px gaps, 56px primary brand row with equal 16px top/left insets, and optical alignment to the visible B. Labs differs only in descriptor weight and color. Native products use equivalent logical units and the same visual criteria.

New consumers reuse the shared component/assets and pin a tested version. Do not restore zero tracking or create per-product brand overrides. A later explicit user instruction can revise this standard.
